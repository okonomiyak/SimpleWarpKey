# Simple Warp Key

A Forge 1.20.1 mod that teleports you to the block you're looking at.

## Usage
- Press `G` to warp on top of the block you're looking at (rebindable in Controls).
- Requires OP permission and Creative or Spectator mode.
- Maximum distance: 1000 blocks.

## Requirements
- Minecraft 1.20.1
- Forge 47.x
- Java 17
- Must be installed on both the client and the server.

## Building
    ./gradlew build
The jar is written to `build/libs/`.
